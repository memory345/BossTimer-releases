# Boss Timer (กิลด์ Sixer)

โปรแกรมจับเวลาบอส MU สำหรับสมาชิกกิลด์ Sixer

**ดาวน์โหลดเวอร์ชันล่าสุด:** [BossTimer.exe](https://github.com/memory345/BossTimer-releases/releases/latest/download/BossTimer.exe)

- ต้องใช้รหัสผ่านเข้าโปรแกรม ขอได้จากหัวกิลด์
- อัปเดต: ปิดโปรแกรมก่อน แล้ววาง `BossTimer.exe` ตัวใหม่ทับไฟล์เดิม (ค่าตั้งเดิมยังอยู่)
- repo นี้เก็บเฉพาะไฟล์ .exe และ `version.json` ที่โปรแกรมใช้เช็กเวอร์ชันใหม่
